## Why multiple courses

No single course covers everything well. The plan: go deep on a few, skim the rest for what they do best. One is strongest on UX process (Google), another on Figma (Instructory #3, IBM), another on developer-focused UI (Scrimba). Items 1-5 are the 30-day commitment; Google is the long deep dive; Microsoft and IBM are skim-and-reference.

## Folder layout

Every course folder follows the same structure so the notes are easy to navigate:

- `notes.md` — the main learning notes, written to be readable standalone
- `curriculum.md` — full lecture list with durations (checklist while following along)
- `slides/` — key slides captured from the course, named by topic

Slides are from paid courses, so this repo stays private and is shared with the team only.
